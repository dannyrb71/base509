# Cartoon environment PNGs

Nine original standalone environment assets plus three overview sheets, generated with the built-in image-generation workflow to match the cartoon dog PNG set.

## Standalone assets

- `tree-1.png`, `tree-2.png`, `tree-3.png`
- `bush-1.png`, `bush-2.png`, `bush-3.png`
- `cloud-1.png`, `cloud-2.png`, `cloud-3.png`

## Overview sheets

- `trees-sheet.png`
- `bushes-sheet.png`
- `clouds-sheet.png`

Every file uses real RGBA transparency with transparent padding.

## Final prompt set

Shared direction: transparent environmental asset sheets matching the existing dog illustrations; three clearly separated original variations per category; loose flat mid-century children's illustration; hand-painted irregular silhouettes; subtle dry-brush texture; sparse detail; warm whimsical personality; minimal linework; no heavy outlines, scenery, ground lines, shadows, text, borders, or watermarks.

- Trees: tall crooked, short wide, and playful leaning silhouettes; muted sage and olive foliage with warm ochre highlights and caramel-brown trunks.
- Bushes: low wide hedge, airy twiggy bush, and compact clustered bush; muted sage, olive, moss, ochre, and caramel twigs.
- Clouds: long low, small tilted, and tall three-puff silhouettes; warm cream, pale blue-gray, and muted blue.

The three dog PNGs were used as style, palette, and texture references only.
