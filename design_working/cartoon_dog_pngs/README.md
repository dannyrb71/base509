# Cartoon dog PNGs

Three original raster illustrations generated with the built-in image-generation workflow, using the supplied images as style references only:

- `dog-walking.png` — jaunty side-view walk
- `dog-playing.png` — clear play-bow pose
- `dog-begging.png` — upright begging pose with curled paws

All files use real RGBA transparency and have transparent padding around the character.

## Final prompt set

Shared direction: a single original dog isolated on genuine transparency; loose flat mid-century children's illustration; irregular hand-drawn silhouette; simple shapes with subtle dry-brush texture; sparse facial marks; exaggerated snout and asymmetrical ears; warm ochre, caramel, cream, dark chocolate, and a red-orange collar; no text, border, shadow, watermark, heavy outline, 3D rendering, photorealism, or copied reference character.

- Walking: energetic side-view stride with opposing legs extended and lifted tail.
- Playing: unmistakable play bow, front legs stretched low, rear raised, open happy mouth, and wagging tail.
- Begging: balanced upright on the haunches with both front paws curled loosely and an eager upward expression.

The supplied images were treated as style references, not edit targets.
